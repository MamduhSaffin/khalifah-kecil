# Khalifah Kecil

Production source for https://khalifah.tgpu.my/.

Khalifah Kecil is a Malay-language, offline-capable real-world curiosity, invention and life-learning experience for children. Progress is stored locally on the child's device.

## Deployment

The `main` branch deploys through GitHub Actions to Azure Static Web Apps. Treat changes to `main` as production changes and verify the live domain after deployment.
